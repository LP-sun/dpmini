🚀 快速开始命令

1. 激活环境
   conda activate ai4m

2. 运行测试
   pytest tests/test_descriptor.py -v

3. 快速训练 (500步, ~2 分钟)
   python train_cpu.py --config se_e2_a/input_torch_test.json --data-dir collect/O64H128

4. 完整训练 (100000步, ~2 小时)
   python train_cpu.py --config se_e2_a/input_torch.json --data-dir collect/O64H128

5. 推理
   python inference.py --model exports/model_*.pth --input collect/O64H128
