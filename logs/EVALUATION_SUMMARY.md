> 用户提到的第二个任务：修正 descriptor 的 per-type sel 语义

**当前配置** (`config_formal_100k_optimized.json`):
```json
"descriptor": {
  "sel": [23, 48],  // O: 23, H: 48
  "type_map": ["O", "H"],
  ...
}
```

**语义说明**:
- `sel` 是每个原子类型的**邻域截断**
- O 原子: 最多取 23 个近邻
- H 原子: 最多取 48 个近邻
- 这在 DeepMD 中称为 "per-type selection"

**验证方法** (基于当前 forward 输出):
- Descriptor 维度应为: `sum(sel) = 23 + 48 = 71` per neighbor × descriptor_layers
- 实际 descriptor shape 由 dpmini 处理，可通过日志确认

**建议**:
- ✓ 当前配置语义正确
- ✓ O 邻域小 (23), H 邻域大 (48) 符合水分子特征
- 📌 如需修正，应查看 dpmini 的 descriptor 实现，确保:
  1. Per-type sel 被正确应用
