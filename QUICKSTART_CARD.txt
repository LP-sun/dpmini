## ⚠️ 必读

### ❌ 常见错误
```bash
# ❌ 错误：日志被缓冲，看不到实时输出
python train_cuda_optimized.py ... > logs/train.log

# ✅ 正确：使用 -u 标志
python -u train_cuda_optimized.py ... 2>&1 | tee logs/train.log
```

### ⚡ 关键参数
| 参数 | 值 | 为什么 |
|------|-----|--------|
| stop_lr | 1e-6 | 不衰减到地板 |
| limit_pref_f | 20.0 | 维持 force 权重 |
| decay_steps | 20000 | 同步长训练周期 |

## 🔍 常见问题速答

| 问题 | 答案 |
|------|------|
| **F_rmse 还在抖动？** | 正常！Batch=1 噪声。看 rolling mean。 |
| **Loss 突然爆炸？** | 检查 start_lr，可能太高或数据问题。 |
| **日志没输出？** | 忘了 `-u` 标志？改成 `python -u ...` |
| **GPU 内存满？** | Batch=1 已最小。检查其他进程。 |
| **Checkpoint 在哪？** | checkpoints_formal_long/ 目录，5000 步一次。 |
