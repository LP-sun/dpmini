⚠️  关键问题分析
───────────────────────────────────────────────────────────────────────────────

【问题1】能量预测能力严重下降 (最关键)
  ┌─ 现象 ──────────────────────────────────────────────────────────────┐
  │ V3的e_rmse = 0.7736 是原始0.1718的4.5倍                            │
  │ 这表明V3几乎失去了能准确预测能量的能力                            │
  └──────────────────────────────────────────────────────────────────────┘
  
  ┌─ 可能原因 ──────────────────────────────────────────────────────────┐
  │ 1. 批大小变化 (1→4): 梯度平均化削弱能量学习                        │
  │ 2. 梯度累积4步: 能量梯度延迟可能导致优化方向偏差                  │
  │ 3. 超参数不适配: 损失权重pref_e未针对新架构调整                   │
  │ 4. 批处理语义: 能量是全局性质,可能对批处理更敏感                  │
  └──────────────────────────────────────────────────────────────────────┘

【问题2】总损失波动加大
  原始Loss Std = 120.4  →  V3 Loss Std = 240.4 (+100%)
  表明优化过程变得更不稳定

【问题3】优化效率未改善
  期望: DataLoader异步加载提升性能
  实际: 1.59 step/s (原始) vs 1.54 step/s (V3)
  原因: GPU资源竞争 + 初始化开销
